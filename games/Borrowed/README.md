# Borrowed

**Status:** In development  
**Engine:** Unity 6  
**Genre:** Puzzle adventure

You are a spirit orb that survives by possessing hosts. Each host is won by solving its own puzzle, played with your voice, microphone and webcam, or with keyboard and mouse.

## Features in progress

- Possession mechanic with a unique puzzle per host
- Voice, microphone and webcam input, with keyboard and mouse fallback
- Predator AI that hunts the orb
