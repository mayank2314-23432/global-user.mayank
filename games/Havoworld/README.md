# Havoworld

**Status:** In development  
**Engine:** Unity  
**Genre:** Destruction sandbox

A physics destruction sandbox. Structures fracture into chunks and debris based on where and how hard they are hit, so every collapse plays out differently.

## Features in progress

- Impact-based fracture of structures
- Chunk and debris physics with pooling for performance
- Camera shake and impact effects
